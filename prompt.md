# Website Creation Prompt for GitHub Copilot

## Objective
Create a **modern, professional, multi-page static website** inspired by the **structure, layout, and user experience** of the reference website:

https://skaiair.com/

⚠️ Important:
- Do NOT copy code, images, text, or branding from the reference site
- Use original content and placeholders
- Take inspiration only from layout, flow, UX, and visual hierarchy

---

## Tech Stack
- HTML5
- CSS3 (Flexbox + Grid)
- Vanilla JavaScript
- Tailwind CSS (preferred, optional)

---

## Pages to Build
1. Home
2. About Us
3. Services

## Design & UX Guidelines
- Clean, premium, corporate look
- Light theme with subtle gradients
- Smooth scrolling and micro-interactions
- Sticky navigation bar with active menu highlight
- Clear CTA buttons (Contact Us / Get Quote)
- Fully responsive (mobile, tablet, desktop)
- Consistent spacing, typography, and color system
- Modern animations (hover, fade, slide-in)
